========================================
STACK COMPLETA - SISTEMA IMOBILIÁRIO COM IA
TEMPLATE GENÉRICO E REPLICÁVEL
========================================

OBJETIVO:
Sistema completo para imobiliárias com atendimento por IA no WhatsApp, memória de lead, CRM visual, follow-up automático, base de conhecimento e entrega de lead qualificado para corretor.


========================================
1. INFRAESTRUTURA
========================================

VPS / CLOUD
- DigitalOcean ou similar
- Pago
- Recomendado: 1 VPS por cliente, se vender ambiente dedicado

DOCKER
- Gratuito
- Usado para subir n8n, WAHA e serviços auxiliares

N8N SELF-HOSTED
- Gratuito
- Cérebro das automações
- Onde ficam os workflows de atendimento e follow-up

WAHA
- Gratuito/self-hosted
- Responsável pela conexão com WhatsApp

OPENAI
- Pago conforme uso
- Modelo recomendado: gpt-4o-mini
- Usado para classificação, SDR, respostas, filtros e extrações

SUPABASE
- Pago em produção
- Banco de dados / CRM / memória / base de conhecimento
- Recomendado: 1 Supabase por cliente

NEXT.JS
- Gratuito
- Framework do CRM visual

VERCEL
- Gratuito/pago
- Hospedagem do CRM visual

DOMÍNIO / DNS
- Hostinger ou similar
- Pago
- Usado para domínio do CRM, site ou subdomínio do cliente

TELEGRAM
- Gratuito
- Alertas internos para corretor, gerente ou suporte técnico


========================================
2. FUNCIONALIDADES DO SISTEMA
========================================

- Atendimento automático via WhatsApp
- IA SDR pré-vendedora
- Memória de lead
- CRM visual integrado
- Follow-up automático de 2h e 24h
- Sistema anti-ban para follow-up
- Base de conhecimento da imobiliária
- Busca inteligente de imóveis no site/sitemap
- Validação de cidade atendida
- LGPD automático
- Trava de corretor: só encaminha lead quando fizer sentido
- Entrega de lead qualificado para corretor
- Alertas por Telegram
- Painel CRM em Next.js/Vercel

========================================

WhatsApp do cliente
↓
WAHA
↓
n8n
↓

Resposta para cliente / alerta para corretor / CRM visual

========================================
6. MÓDULO VERCEL + NEXT.JS — CRM IMOBILIÁRIO
========================================

OBJETIVO:
Subir um CRM visual exclusivo para cada imobiliária usando Next.js + Vercel.

O CRM serve para:
- visualizar leads
- acompanhar status
- ver origem dos contatos
- consultar score/temperatura
- acompanhar imóveis de interesse
- organizar atendimento da equipe


ESTRUTURA REPLICÁVEL:

Para cada cliente:

1. Duplicar o projeto CRM
2. Criar Supabase exclusivo
3. Configurar .env.local
4. Subir na Vercel
5. Configurar variáveis na Vercel
6. Conectar domínio ou subdomínio
7. Testar login
8. Entregar link ao cliente


ARQUIVO .env.local:

NEXT_PUBLIC_SUPABASE_URL=https://SEU_PROJECT_REF.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=SUA_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY=SUA_SERVICE_ROLE_KEY

NEXT_PUBLIC_CLIENTE_NOME=NOME_DA_IMOBILIARIA
NEXT_PUBLIC_CLIENTE_CIDADE=CIDADE_ATENDIDA

CRM_LOGIN_EMAIL=EMAIL_DO_CLIENTE
CRM_LOGIN_PASSWORD=SENHA_DO_CLIENTE


VARIÁVEIS NA VERCEL:

Vercel
↓
Project
↓
Settings
↓
Environment Variables

Adicionar as mesmas variáveis do .env.local.
Depois fazer Redeploy.


DEPLOY VIA GITHUB:

1. Subir CRM para repositório GitHub
2. Importar projeto na Vercel
3. Configurar variáveis
4. Deploy


DEPLOY VIA VERCEL CLI:

npm install -g vercel

Dentro da pasta do CRM:

vercel

Para produção:

vercel --prod


DOMÍNIO / SUBDOMÍNIO:

Exemplos:

crm.nomeimobiliaria.com.br
painel.nomeimobiliaria.com.br
app.nomeimobiliaria.com.br

Na Vercel:

Project
↓
Settings
↓
Domains
↓
Add Domain

Na Hostinger/DNS:

Adicionar CNAME:

crm → cname.vercel-dns.com


REGRA DE SEGURANÇA:

Nunca colocar service_role key no front-end.
Pode usar service_role apenas no backend/API routes.
Nunca expor no navegador.
Nunca colocar no GitHub público.

No front-end usar:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY

No backend/API routes usar:
SUPABASE_SERVICE_ROLE_KEY
